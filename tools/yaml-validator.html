What is YAML?

YAML (YAML Ain't Markup Language) is a human-friendly data serialization standard designed for readability. Unlike JSON, YAML uses indentation-based structure instead of braces and brackets, making it ideal for configuration files. It is widely used in DevOps (Docker Compose, Kubernetes manifests), CI/CD pipelines (GitHub Actions, GitLab CI, CircleCI), infrastructure-as-code (Ansible, Terraform), and application settings (Spring Boot, Ruby on Rails).
